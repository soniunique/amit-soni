# Cloud Architect Portfolio

Lovable Prompt — Amit Soni Personal Brand Website

Copy everything in the code block below and paste it as your prompt in Lovable.

Build a personal brand / portfolio website for a senior cloud infrastructure leader named Amit Soni. This is a one-page (or lightly multi-section) professional site meant to establish credibility with enterprise clients, recruiters, and technology peers — not a flashy startup landing page. The tone should feel like "quiet expertise": precise, dependable, technically deep, understated confidence. Think enterprise architect, not influencer.

PERSONA TO REFLECT
- 18+ years in cloud consulting and infrastructure (Accenture, Oracle, 3i Infotech)
- Currently Cloud Infrastructure Manager at Accenture; previously Principal Consultant at Oracle
- Deep specialist in Oracle Cloud Infrastructure (OCI), Azure, WebLogic/middleware, database administration, and large-scale cloud migration & modernization
- Multiple Oracle Cloud certifications (Architect Associate, Multicloud Architect Associate, and others)
- Mission-driven: delivers high-quality solutions, empowers his team, enjoys hard technical troubleshooting
- Personality: methodical, reliable, collaborative, technically rigorous, calm under complexity — the person a team leans on when a migration is on fire at 2am

SITE STRUCTURE
1. Hero section
   - Name: Amit Soni
   - Tagline: "Cloud Infrastructure Leader | Oracle Cloud (OCI) Expert | 18+ Years Turning Complex Migrations into Reliable Systems"
   - Short one-line subtext on his mission (deliver high-quality cloud solutions, empower teams)
   - Primary CTA: "View Experience" or "Connect on LinkedIn" (link to https://www.linkedin.com/in/amit-soni-55805821/)
   - Secondary CTA: "Download Resume" (placeholder button)

2. About section
   - Rework this into 2-3 short paragraphs: 18+ years in consulting & technology, cloud architect and operations leader at Accenture, helps clients migrate and manage cloud infrastructure/middleware/databases, multiple Oracle Cloud certifications, skilled across WebLogic/SOA/OSB/ODI/OIC, Linux, OCI, Azure (IaaS/PaaS/DBaaS), enjoys troubleshooting and continuous learning, mission to deliver high-quality solutions and support his team.

3. Experience timeline (reverse chronological, with company logos/icons as simple monochrome marks)
   - Cloud Infra Manager, Accenture — Jun 2025-Present
   - Cloud Ops A Manager, Accenture — Apr 2021-Jun 2025
   - Principal Consultant, Oracle — Jun 2016-Apr 2021
   - Senior Software Engineer, Accenture — Oct 2010-Jun 2016
   - Engineer Technology Solutions, 3i Infotech Ltd. — Jan 2008-Oct 2010
   - Present as a clean vertical timeline with role, company, dates, and 1-line impact summary per role

4. Core skills / expertise grid
   - Cloud Platforms: OCI, Azure
   - Middleware: WebLogic, SOA, OSB, ODI, OIC
   - Infrastructure: IaaS, PaaS, DBaaS, Linux
   - Specialties: Cloud Migration, Cloud Modernization, Oracle Database Administration
   - Display as icon + label cards in a responsive grid

5. Certifications section
   - Highlight Oracle Cloud Infrastructure Certified Architect Associate and Multicloud Architect Associate (mention "12 Oracle Cloud certifications" as a credibility stat)
   - Simple badge/card layout

6. Contact / footer
   - LinkedIn link, location (Noida, Uttar Pradesh, India), simple contact form or mailto CTA
   - Understated footer, no social clutter beyond LinkedIn

DESIGN DIRECTION — THEME, COLOR & FONT
- Overall mood: enterprise-grade, trustworthy, technical precision — like a well-built system: no wasted motion, everything load-bearing
- Color palette: deep navy / slate blue as the primary (#0F1B2D or similar dark blue-slate), paired with a clean off-white/light-gray background (#F7F8FA), and ONE confident accent color — a muted cloud/tech blue (#3E7CB1 or #2D6CDF) for links, buttons, and highlights. Optionally a very restrained warm accent (soft amber #E8A33D) used sparingly for certifications/highlights only — echoes the Oracle red without literally using Oracle's brand red.
- Avoid bright gradients, neon, or playful startup colors — keep it corporate-credible but not cold or sterile; add warmth through generous whitespace and confident typography rather than color.
- Typography: a clean geometric/grotesk sans-serif for headings (e.g., "Inter", "IBM Plex Sans", or "Sora") to signal engineering precision, paired with a highly readable sans-serif for body text (e.g., "Inter" or "Source Sans Pro"). Avoid decorative or script fonts entirely — nothing should feel casual.
- Layout: generous whitespace, clear grid alignment, subtle dividers rather than heavy borders, minimal use of shadows/gradients — the visual equivalent of well-architected infrastructure: modular, organized, nothing overbuilt.
- Motion: subtle only — gentle fade/slide-ins on scroll for timeline and skill cards, no flashy animation. This person's brand is reliability, not spectacle.
- Responsive: fully mobile-friendly, since recruiters and clients will often view on mobile.

Build this as a polished, production-ready single scrolling page with smooth anchor navigation (About / Experience / Skills / Certifications / Contact) in a sticky top nav bar.
